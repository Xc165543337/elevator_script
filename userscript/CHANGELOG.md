## [1.2.1] — 2026-11-26

油猴脚本无变化；本次只更新 Python 版。

### Python 版

- 马尔可夫策略遇到打不过的首领墙时撤离：预计还能击败的首领数（假设每个整备窗口都回满）低于 0.3 时撤离带回背包；打不赢的首领不再硬打，直接撤离或用烟雾弹脱出（同样算撤离）。背包里有替身娃娃时不撤离

## [1.2.0] — 2026-11-25

适配 2026-11-25 的服务器更新（精英整备、追寻祝福、闪耀祝福、遭遇概率调整）。**升级后建议先打一局练习确认。**

### 新增

- 正式下潜带上两套追寻祝福（沿用开局页上次选定的两套）；尚未选择时不开局并提示。进行中的正式局需要补选时自动补发
- 每局结束时记录新获得的闪耀祝福部件

### 变更

- 精英战按新规则估算：先估到第 8 回合整备，整备时重新决策（用药 / 继续），之后估到第 16 回合；普通怪按 15 回合上限估算（原来不设上限）
- 读取服务器的「打击减伤」二级属性
- 开局前把连战设为遇奇遇暂停、遇精英暂停（不自动打精英），与决策模型的假设一致
- 默认携带物资改为带满：7 种商店回复药与烟雾弹各 50 个（服务器单种上限），外加 2 支肾上腺素。保存的设置仍是旧默认值时自动换成新默认值；改过的保持不变
- 续玩进行中的对局时同样调整连战设置；服务器不允许时只记录提示，不中断

### Python 版（同一版本一起发布）

油猴脚本仍使用阈值策略；以下改动只在 Python 版（`farm.py`）中：

- 新增马尔可夫决策策略（`--policy markov`）：按楼层与有效生命逐层求解，回复药、烟雾弹按预算定价；精英整备、首领窗口、追寻祝福、闪耀祝福、深层破甲（缺刻值夜表等套装）均已建模
- 遗物盒估值 ≥ 1000 万时舔包，放不进安全箱的部分（≥ 1000 万）撤离带回；更便宜的捞尸换赏金
- 「为了我所期待的」只在用最好的回复后仍有 ≥ 5% 死亡风险时使用，且不会清掉 ≥ 1500 万的本局拾取
- 风隙羽标的逃跑加成、深层破甲公式、新版遭遇概率均已计入；服务器重启（HTTP 502）时等待重连

## [1.1.0] — 2026-11-25

同步 Python 版根据实战调整的决策规则与校准数据。**升级后建议先打一局练习确认。**

### 变更

- 回复手段（药品、手术匣、野外回复）全部用完时，在下一个安全时机撤离，带回背包
- 用尽回复与增益后，战斗死亡概率仍高于 10% 就撤离（原为 35%）；没有任何回复时，超过可接受风险即撤离
- 背包里捡到替身娃娃（死亡时保住背包）时不撤离，继续深入刷首领
- 判断能否连战时不计入限层增益（连战跨越多层，增益可能中途失效），改用最近一次无增益时的属性
- 只剩战地手术匣时，HP 低于 30% 才在遭遇中使用（原为 55%），简单战斗不再浪费手术匣
- 不再使用扩容袋：扩容袋珍贵，捡到的带回家
- 默认携带物资改为只带回复与肾上腺素：`adrenaline=2,ice_tea=50,coffee=50,triage_vial=50,slow_serum=50,barrier_serum=50,critical_serum=50,field_surgery=50`。保存的设置仍是旧默认值时自动换成新默认值；改过的保持不变
- 浏览器中尚无校准数据时，从 Python 版最新的校准系数起步

### 新增

- 「仓库去重」按钮：对仓库中的红 / 金物品执行「每种只留价值最高的一件」规则，其余出售；不开局，不出售其他稀有度（对应 Python 版 `--sell-now`）

## [1.0.0] — 2026-11-25

首个版本：把 Python 版刷首领代理（`elevator_agent`）移植为油猴脚本，直接在游戏页面里运行。

### 新增

- 游戏页面右下角的悬浮面板：开始、本局后停止、立即暂停、查看状态；实时显示局数、楼层、HP、首领数与彩虹掉落
- 沿用页面已登录的会话：不需要也不会保存账号密码
- 面板内可配置全部参数：练习 / 正式模式、地图、局数、最高层、携带物资、自动补货、购买付费门票、金币保留线、出售战利品与稀有度、「伤害 ×2」临装评分、请求间隔、详细日志
- 正式模式开始前弹窗确认将消耗的门票与金币
- 设置、校准系数与每局记录保存在浏览器中；可导出每局记录（CSV）与最近 500 步的决策轨迹（JSONL）
- 防止多个标签页同时运行（各自的 revision 会互相冲突）
- 决策、战斗模拟、装备换算、奇遇与临装评分、校准与 Python 版逐项对照测试：练习局轨迹中的 254 个状态决策完全一致
- 版本发布：推送版本标签后自动检查并创建 GitHub Release，附带 `elevator-farmer.user.js`，正文取自本更新日志（仓库公开时油猴可据此自动检查更新）

### 修复（同时修复 Python 版）

- 判断能否连战时，连续战斗风险一直按废弃商场的怪物计算；在其他地图（如天顶，怪物强度 ×4.45）会低估风险而冒进连战。现在按当前地图计算
